# chantios-media

Visuels publics de la page Facebook Chantios (https://www.facebook.com/chantios.fr) : images et Reels, publiés via Metricool.
Aucun code. Les fichiers sont retirés une fois publiés.

Site : https://chantios.fr

## Captures pour les testeurs

`captures-testeurs/<date>/` : captures d'écran du site en mode démonstration (données fictives), liées depuis le document « Fonctionnalités et tests » du projet. Ces fichiers restent en place (ils ne sont pas copiés par Metricool) ; les remplacer par un nouveau dossier daté quand l'écran change.
